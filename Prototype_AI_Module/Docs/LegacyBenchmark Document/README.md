# LegacyBenchmark Document

Thư mục này lưu tài liệu benchmark cũ của khối NodeJS/React.

## Mục đích

- giữ lại dữ liệu benchmark và ground truth cũ để tham chiếu
- tránh trộn với tài liệu của prototype `.NET` đang active

## Ghi chú sử dụng

- không xem đây là nguồn đặc tả chính của module hiện tại
- nếu đang làm với code active, ưu tiên đọc `Docs/Prototype_Document/`
- chỉ quay lại đây khi cần đối chiếu benchmark cũ, test file cũ hoặc dữ liệu lịch sử
