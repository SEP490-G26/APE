# Docs

Tài liệu trong repo được chia thành 2 khối:

- `LegacyBenchmark Document/`
  - tài liệu benchmark cũ của khối NodeJS/React
- `Prototype_Document/`
  - tài liệu của prototype `.NET` đang active

## Cách đọc

Nếu đang làm việc với code hiện tại, ưu tiên đọc:

1. `Prototype_Document/Guides/`
2. `Prototype_Document/Specs/`
3. `Prototype_Document/DB_Resources/`

Nếu chỉ cần đối chiếu benchmark cũ, xem:

- `LegacyBenchmark Document/`
