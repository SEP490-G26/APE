# src-dotnet

Thư mục này chứa prototype `.NET` đang active của AI module.

Đây là khối được ưu tiên để:

- benchmark
- production testing
- so sánh model / cost / output
- làm nền để merge vào BE thật sau này

- solution: `Ape.AiModule.slnx`
- web app: `Ape.AiModule.Api`
