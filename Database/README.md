## 📖 Overview

This directory contains the complete database dump (20 JSON collection files) for the **APE (AI-Powered Examination and Programming Practice Platform)** database (`APE_DB`).

These collections contain all necessary seed data, active AI prompts, pedagogical evaluation rubrics, system settings, courses, user accounts, knowledge chunks with **Cohere 1024-dimensional vector embeddings**, generated question banks, practice exams, and wallet billing transaction records.

---

## 📑 Exported Collections (20 Files)

| Collection File | Collection Name | Purpose & Contents |
|---|---|---|
| `APE_DB.SystemSettings.json` | `system_settings` | Global platform settings, API base URLs, security thresholds |

| `APE_DB.PEQuestions.json` | `pe_questions` | Practical coding problems, skeleton code, solution code, test cases |

## 🚀 Fast Automated Import (Recommended)

### Option 1: Using PowerShell (Windows)
Run the automated import script from within this `Database/` directory:

```powershell
# Import to default local MongoDB (mongodb://localhost:27017)
.\import_database.ps1

# Import to custom Local URI or MongoDB Atlas Cloud:
.\import_database.ps1 -Uri "mongodb+srv://<username>:<password>@cluster.mongodb.net/APE_DB"
```

### Option 2: Using Bash (Linux / macOS)
```bash
chmod +x import_database.sh

# Import to local MongoDB
./import_database.sh

# Import to MongoDB Atlas Cloud:
./import_database.sh "mongodb+srv://<username>:<password>@cluster.mongodb.net/APE_DB"
```

### Method 2: Using MongoDB Compass (GUI)
1. Open **MongoDB Compass** and connect to your instance (`mongodb://localhost:27017` or Atlas URI).
2. Create or select database **`APE_DB`**.
3. For each collection:
   - Click **Create Collection** (e.g., `courses`).
   - Click **Add Data** $\rightarrow$ **Import JSON or CSV file**.
   - Select the corresponding JSON file (e.g., `APE_DB.Courses.json`) and choose **JSON**.
   - Click **Import**.

## ⚙️ Post-Import Verification & Index Initializer

When you run **`APE_BE`** for the first time after database import:
- The backend's `MongoBootstrapService` automatically runs index migration scripts, ensuring all unique indexes, compound search keys, and TTL indexes are established automatically.
- Check that the connection string in `APE_BE/API/appsettings.Development.json` or `.env` points to:
  ```json
  "ConnectionStrings": {
    "MongoDb": "mongodb://localhost:27017/APE_DB"
  }
  ```
